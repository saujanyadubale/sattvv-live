# SAT-V&V — GitHub Pages research showcase

This folder is a standalone **static replay** of three genuine, archived synthetic SAT-V&V simulations.
GitHub Pages cannot execute the Python backend. **The scenario selector does not generate new results.** It switches archived records.

Publish: place this folder at `satvv/` in `saujanyadubale.github.io` and commit. Visit `https://saujanyadubale.github.io/satvv/`.

The research engine remains in the separate full source archive and runs with `python -m satvv serve`.
The visualized spacecraft is conceptual and measurements synthetic.
