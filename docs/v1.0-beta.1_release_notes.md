# SAT-V&V v1.0 beta.1 — Release notes

## Changes requested by user

1. **More credible ground segment illustration:** procedural parabolic reflector of revolution (lathe geometry), supporting ribs, feed tripod and horn, azimuth/elevation mounts, equipment shelter, service pad. Ground terminal has been made smaller and moved farther from the spacecraft for a clearer visual hierarchy. No real antenna CAD was acquired or embedded; the antenna is a conceptual 3D model.
2. **Less obstructive spacecraft labels:** Clean mode highlights only the active/failed or revealed fault-associated subsystem, Annotated shows all, Hidden removes the labels. In the optional WebGL viewer labels are compact; the offline fallback also supports modes and smaller labels.
3. **Actual system flowchart:** explicit arrowheads from dynamics through telemetry, branching monitoring/forecasting, Bayesian hypothesis updates, test selection, procedure execution, verification evidence audits, and feedback to the next simulation decision. Offline training/calibration nodes feed frozen models back to the runtime system, and are visually differentiated.
4. Keyboard-accessible diagram inspection and link to the existing detailed models guide.
5. Source compatibility and unchanged simulation algorithms verified by regression suite.

## Why the 3D model is still conceptual

SAT-V&V operates on a generic synthetic spacecraft model without a flight-specific mechanical layout or electrical harness. Exact fault location cannot be inferred from abstract subsystem simulation. The local dish illustrates a ground station; it is not a detailed CAD representation of a named facility. Optional NASA ICECube asset is not bundled, and must not be interpreted as this simulator's actual geometry. No radio propagation or real orbital movement is being visualized.

## Reproduction

`conda activate satvv`

`python -m unittest discover -s tests -v`

`python -m satvv serve`

Open `/how-it-works` and `/challenge`. Select Clean, Annotated or Hidden while the replay runs. When networking is unavailable, the bundled projection canvas remains usable.

## Key files

- `web/mission_beta.js`: Three.js procedural ground antenna and label controls.
- `web/mission3d.js`: dependency-free fallback antenna projection and label controls.
- `web/how-it-works.html`: graph SVG with directed edges and clickable nodes.
- `web/workflow_beta.js`: stage descriptions, click and keyboard interactions.
- `web/style.css`: graph and scene styling.

## Scientific validation status

All physically substantive science is unchanged from v1.0 beta. Visual and regression validation are software tests, not spacecraft hardware qualification.
