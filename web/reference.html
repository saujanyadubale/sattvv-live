03 / IMPLEMENTED METHODS

Algorithms and evidence semantics

Monitoring

Thresholds, CUSUM, local slopes, physics residuals and supervised/unsupervised ML. An early warning is not a requirement failure.

Forecasting

Persistence, physics estimates, linear trends and gradient boosting; calibrated only on synthetic datasets.

Diagnosis

Expert-defined, requirement-level Bayesian likelihood updates produce uncalibrated hypothesis weights.

Scheduling

Fixed, temporal-adaptive, information-gain, Random Forest ranking and predictive-active test selection.

Verification

Completed procedures test specific requirements under simulated operating conditions.

Audit

Independent rule checks compare supported numerical evidence, timestamps and policy provenance—internal software consistency, not hardware truth.

For precise method parameters see docs/v0.9.9_models_and_algorithms.md. For data/benchmark protocols see docs/v0.9.4_protocol.md and the v0.9.4 pilot results.
